🔧 Firebase Setup Required
Open this file in a text editor and paste your Firebase config into the script block at the bottom. Here's how:
1
Go to console.firebase.google.com → Create a project (name it anything)
2
In your project: Build → Realtime Database → Create database → choose any region → Start in test mode
3
Go to Project Settings (gear icon) → Your apps → click </> Web → Register app → copy the firebaseConfig object
4
Open paytracker.html in a text editor → find const firebaseConfig = { near the bottom → replace the placeholder values with your copied config
5
Save the file and re-open it — this screen will disappear and your tracker will be live
💡 Test mode lets anyone with the URL read and write — perfect for sharing with your chatter. Your data is only accessible to people you share the link with.
